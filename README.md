# Demo Mode 2 · RewardRush

Static reward-campaign landing page for ChocoScan browser-threat demonstrations. Uses fictional branding and a polished promotional layout.

All buttons trigger local preview notices only. No personal information is collected, no reward is issued, and no external destination is opened.

## Deploy manually to Netlify
1. Download this repository as a ZIP and extract it.
2. In Netlify, choose manual deploy.
3. Drag the extracted project contents into the deploy area. Keep `index.html`, `assets/`, and `netlify.toml` together.

## Files
- `index.html`: page layout
- `assets/css/style.css`: responsive styling
- `assets/js/app.js`: local-only button responses
- `assets/favicon.svg`: tab icon
- `netlify.toml`: static publishing settings
